Homework 02 – Endless Runner
Princess Dungeon Runner
This game is an endless 2D runner, the player runs through a dungeon avoiding obstacles and collecting coins and gems.
How to Play
- A or Left Arrow – Move Left
- D or Right Arrow - Move Right
- Space - Jump
Avoid the obstacles and use gem power-ups to help survive.
Score
The score is based both on distance traveled and coins collected. The coins give 100 points.
Gems
- Speed Gem (Blue) - Increases player’s speed
- Jump Gem (Green) - Increases player’s jump height
- Slow Gem (Red) – Slows down the game speed
Obstacles
- Crate – Static, does not move
- Mace – Swings back and forth
- Arrow – Shoots horizontally
Hitting any of the obstacles will result in a game over.
Game Over
Once the game comes to an end, the player can choose:
- Main Menu
- Play Again

Main Menu
From the main menu, player can choose to play or look at high scores.
High Scores
High score scene tracks the top 5 scores that the player gets.
